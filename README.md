# Simulador Preventa - AC Móvil

Proyecto Java (NetBeans/Ant) con pruebas unitarias y una demo web.

## Pruebas
- `TestCalidad`: 25 pruebas del modelo (JUnit 4.13).
- `TestCalidadBD`: prueba de integración con SQLite en memoria.
- Para ejecutarlas: abrir el proyecto en NetBeans, clic derecho en el proyecto → Test (Alt+F6).
